# Rebuilt Summoner’s Rift

Open Assets/Scenes/LeagueVR.unity, or Tools > League VR > Open Playable Scene.

The scene uses editable native meshes/materials reconstructed from the supplied original OBJ/MTL ZIP. Original Riot artwork is retained. The original GLB is preserved as a source backup. The new continuous foundation, skirt and collision boundary repair the playable floor. Existing XR, Gwen and gameplay scripts were preserved. Lane waypoint data and original League model material texture offsets were corrected during verification.

Full changes, test results, limits, screenshots and source credits: Logs/MapRebuild/Map-Review.md.
